## 4. S04 — Ukrainian copy production plan

1. **Freeze S03.** Confirm the seven-row architecture, exact link destinations and claim crosswalk. Record the accepted architecture hash. Default community placement3 decision: retain return intent, narrow it to people planning return to Lviv/actual locality and link the existing Lviv hub, using the existing Facebook/social/route_launch tuple. This avoids an outbound Hannover destination. If its audience remains Hannover-arrival, rewrite the whole audience/message instead and preserve the outbound link; do not mix those intents.
2. **Draft high-risk replacements first.** Work through the rewrite/remove/await units above. Then read each complete page to remove repetition and preserve a useful next step. Nearby guidance must say that selecting a catalog city does not require travelling there; exact locality is supplied privately and feasibility can be declined. Keep a concise confirmation boundary near the action rather than repeating a warning after every sentence.
3. **Complete all fields.** For each of seven pages, supply exact Ukrainian metadata title/description, H1, intro, section headings/bodies, FAQs, action/helper/fallback labels, source-anchor labels and any changed caption/alt. Include explicit `retain` entries with current text for unchanged fields; no “same as above” implementation placeholders. Hub work also includes nearby intro/8 entries, departure/return copy, resources and route-card descriptions inherited from routes. Shared template copy gets one reusable key and an affected-page list, not seven divergent versions.
4. **Complete support and distribution.** Review the guide, About and imprint against the IDs above, recording no-change where appropriate. Produce all three corrected community drafts, truthful review status, affiliation disclosure and exact destination/UTM. Placement1 loses “найзручніше”; placement2 loses “посадки по дорозі”; placement3 loses direct-service/plural-carrier language and gets a consistent audience/link. Preserve the historical indexing checklist as history; do not treat its submission instructions as current permission.
5. **Editorial review and freeze.** Read complete Ukrainian pages for direction, natural wording, repeated advice and action clarity; then check every changed factual sentence against its claim/source boundary. Record reviewer, actual review date, included/deferred facts and exact package hashes in `editorial-review.md`. Freeze only after all included fields are usable without placeholders. Missing commercial details default to omission or a carrier question; absence of page-level GSC does not prevent this freeze.

Each copy entry should contain: `page URL → stable content key → current source field → retain/rewrite/remove/move → exact final Ukrainian text → claim IDs → supporting source/limitation → downstream fields/components → review status`. This is the implementation contract; examples in this plan do not substitute for it.
