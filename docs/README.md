# Site documentation

Read the relevant canonical contract via [index](index.md). Constitution remains highest product authority. Strategy, research, dated results and Memory belong to the separate [Project KB](knowledge-base.md#knowledge-base). Canonical contracts have exactly one editable original here.

`npm run docs:index` and `npm run docs:check` target this bundle; `npm run check` needs no vault. No source absent-docs bypass.
